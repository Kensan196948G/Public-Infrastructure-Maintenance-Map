## 📋 1. プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| プロジェクト名 | 公開インフラ維持管理マップ（Public Infrastructure Maintenance Map） |
| 目的 | 国・自治体・公的機関の公開インフラ情報（橋梁・道路・港湾・河川・公共施設）を共通形式で地図・検索・一覧・詳細から確認できる「調査の入口」を提供 |

| 提供価値 | 一次情報への誘導、ライセンス制御付き出力、品質バッジによる「調査前スクリーニング」 |
| 完成段階 | MVP Phase 1/2 実装済み・管理機能実装済み・v0.1.0 本番公開済み（2026-07-23） |
| 運用段階 | 本番公開中（ProductionOps）。ただし監視・復旧検証・GitHub 運用設定・管理 E2E は未完了 |
| 技術スタック | React 19 + MapLibre GL / Hono Workers / Neon PostgreSQL + PostGIS / pnpm モノレポ / Cloudflare Pages・Workers / GitHub Actions |
| データ実績 | 実データ 4+ ソース（熊本橋梁・道路 N13・大阪公園・大阪トイレ・港湾 C02 994 件）+ W05 河川 47 県アダプター（パイロット 3 県投入済み） |

## 🤖 8. AI 活用設計（実装は Phase 3。チャット目的化しない）

### 原則

- AI は「時間削減・検索/判断支援・説明可能性・安全性・費用対効果」で評価する
- ルール/検索で十分な領域（重複検出・座標検査・正規化・ライセンス判定）には AI を使わない

### 検討中のユースケース

| ユースケース | 方式 | 入力 | 出力 | 人間承認 | 根拠・引用 |
| --- | --- | --- | --- | --- | --- |
| 自然言語検索 | RAG + 構造化検索ハイブリッド | 質問・検索条件 | 資産一覧＋根拠（原典 URL・属性） | 不要（閲覧のみ） | 常に原典リンクと信頼度表示 |
| 公開資料からの属性抽出 | 構造化抽出（LLM） | PDF/Excel/CSV | アダプター候補 JSON | 要（取込前レビュー） | 抽出元ページ・行範囲 |
| 取込異常の検知 | 異常検知（統計/ルール） | 件数・属性分布履歴 | 警告・要確認リスト | 要（公開判断） | 過去値との偏差 |
| 維持管理計画の参考要約 | RAG | 資産詳細＋公開基準 | チェックリスト要約 | 要（専門家判断） | 法令・点検要領の引用 |
| 利用者向け説明 | 要約生成 | 品質 issue・更新状況 | 平易な説明 | 不要（表示のみ） | 生成内容をログ記録 |

### 必須設計（本ラウンドで文書化）

- **権限制御**: AI は公開データのみ。社内情報・個人情報はデータ方針どおり接続しない
- **プロンプトインジェクション対策**: 外部データをプロンプトに埋め込む際は命令境界を分離・出力検証・原典リンク強制
- **個人・機密情報保護**: 入力に PII を入れない運用＋自動検出（公開データのみのためリスク低）
- **モデル・プロンプト・入出力監査**: 呼出ログ（モデル・トークン・入出力ハッシュ）を監査テーブルへ
- **誤判定時の責任分界**: AI 出力は「参考」で常に免責表示。最終判断は専門技術者・管理主体
- **利用量・予算上限**: 月次上限とアラート、キュー制御、モデル段階（小型→大型）ルーティング
- **停止手段**: 機能フラグ・API キー無効化・モデル設定変更・コスト上限で即時停止
