# ⚖️ ライセンス確認チェックリスト（Adapter License Checklist）

> 対象: Issue #55（データソース拡張基盤）
> 目的: 新規データソース追加時に、利用条件の確認漏れによる法務・再配布リスクを防ぐ。
> 使用タイミング: アダプター追加ガイド（ADAPTER_GUIDE.md）のステップ②。

## 使い方

新規ソースごとに本チェックリストを埋める。**全項目が確認できて初めて追加可能**。1つでも「未確認」がある場合は追加しない（Q007 隔離ではなく、そもそもオンボーディングしない）。

## チェックリスト

| # | 確認項目 | 確認方法 | 結果（✅/❌/未確認） | 備考 |
| --- | --- | --- | --- | --- |
| L-01 | 提供元の正式名称と公開 URL | 提供元サイトの確認 | | |
| L-02 | 利用条件・利用規約のページが存在する | 提供元サイトの「利用規約」「ライセンス」等 | | |
| L-03 | 再配布の可否が明記されている | 利用規約・ライセンス文言 | | allowed / restricted / prohibited を判定 |
| L-04 | 商用利用の可否が明記されている | 利用規約・ライセンス文言 | | 非商用のみ → restricted |
| L-05 | 出典表示（帰属表示）の要件 | 利用規約・ライセンス文言 | | attributionText に反映 |
| L-06 | 改変（変換・加工）の可否 | 利用規約・ライセンス文言 | | 変換は不可のケースがある |
| L-07 | ライセンス名称が特定できる | CC BY 4.0 / 政府標準利用規約 等 | | licenseName に記録 |
| L-08 | ライセンス URL が特定できる | ライセンスへの直接リンク | | licenseUrl に記録 |
| L-09 | 更新日・版数が確認できる | データページの更新情報 | | sourceUpdatedAt の有無判定 |
| L-10 | 機械可読形式（CSV/GeoJSON等）での提供 | ダウンロードリンクの確認 | | API の場合はアクセス方式の確認 |
| L-11 | 取得頻度の制約（負荷・回数制限） | API 仕様・利用規約 | | refresh_cron の設計に反映 |
| L-12 | 個人情報・機微情報が含まれない | データ内容の確認 | | 本プロジェクトは個人情報を扱わない |

## 判定ルール

| redistribution | 意味 | サイトでの扱い |
| --- | --- | --- |
| `allowed` | 再配布・商用利用が明示的に許可 | エクスポート許可（帰属表示付き） |
| `restricted` | 条件付き（非商用・出典必須等） | エクスポート許可（帰属表示付き）＋制約を明示 |
| `prohibited` | 再配布禁止・営利利用禁止 | エクスポート対象外 |
| `unknown` | 確認できない | **オンボーディングしない**（Q007 で隔離されるため無意味） |

## 記録例（既存ソース）

| slug | licenseName | redistribution | 備考 |
| --- | --- | --- | --- |
| `bridge-kumamoto` | CC BY 4.0 International | allowed | 熊本県オープンデータ |
| `facility-osaka-park` | 大阪市オープンデータ（要確認） | allowed | EPSG:6668 |
| `port-c02` | 国土数値情報 C02（非商用条件） | restricted | attributionText に非商用条件を明記 |
| `road-n13` | 国土数値情報 N13 | allowed | 名称未収録のため表示合成 |
| `sample-*` | 架空サンプル | allowed / prohibited | テスト用・実在しない |

## 追加時の提出物

アダプター追加 PR には本チェックリスト（L-01〜L-12）の結果を必ず含める。未記入の PR はレビューで差し戻す。
